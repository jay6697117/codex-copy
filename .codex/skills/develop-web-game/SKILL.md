# Develop Web Game Skill (`$develop-web-game`)

## Workflow Instructions
1. **Architecture & Game Loop**: Scaffold a deterministic `requestAnimationFrame` loop with fixed-timestep physics and responsive keyboard/gamepad controls.
2. **Visuals & Assets**: Pair with `$image-generation` or procedural WebGL shaders to build readable tracks, characters, and particle effects.
3. **Playtest QA Loop**: Launch the in-app Live Preview browser, simulate player inputs, verify FPS and collision boundaries, and fix regressions before completing the turn.
