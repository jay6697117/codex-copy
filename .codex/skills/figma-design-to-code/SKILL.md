# Figma Design to Code (`$figma-design-to-code`)

## Workflow Instructions
1. **Inspect Frame Hierarchy**: Extract spacing, typography, color variables, and responsive constraints from the target Figma node.
2. **Component Synthesis**: Generate clean, accessible React 19 + Tailwind CSS components with interactive hover/focus states.
3. **Visual Diff Verification**: Render the component in the Codex Live Preview pane and verify layout fidelity across desktop and mobile viewports.
